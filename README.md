# 知序 · 军事理论刷题

作者 **baibai**。黑白简约的互动题库，支持浏览器离线使用。

## 下载与使用

前往 [Releases](https://github.com/baibai-gifted/Education/releases) 下载刷题 ZIP，全部解压后双击 index.html。无需安装、登录或启动服务器。

## 功能

- 4,733 道题，含答案和解析，按 10 个辅助学习模块导航。
- 1,644 道预标易混题，答错自动进入个人错题本。
- 顺序或随机练习、搜索、筛选、收藏、续练和学习记录备份。
- 明暗主题、手机布局；作者页仅展示圆形头像、baibai 和下载链接。

原资料缺失的 101 条解析已补充官方出处；6 道疑义题不自动判分。原库全部答案尚未逐题独立事实核验。记录仅保存在使用者自己的浏览器，不自动上传。

[项目源码及构建步骤](military-study/README.md) 位于 military-study/ 目录，Python 标准库即可构建，无需安装依赖。
