# 题库数据与可复现输入

原资料：[2026年军事理论知识竞赛题库-可查看下载.xlsx](https://www.kdocs.cn/l/coCdkuO5iIU8)。通过允许访客查看/复制的公开只读响应提取；未下载原始 XLSX，未核验原始 XLSX 文件哈希。

数据快照版本 3975，75 个查询块涵盖单选 2,233、多选 1,300、判断 1,200，共 4,733 条；稳定 ID 由原工作表和 Excel 行号组成。原题号重号、跳号及重复题均保留。提取时本地查询响应 SHA256 为 `814e48f80889092791ca9976f6141bcf4dec598d5c12ce42cd4fcf33f0985b80`，该值仅指响应证据文件，不代表 XLSX 哈希。

公开构建输入：

- `questions-raw.json`：原题干、选项、答案、解析、出处与源行信息，只读输入。
- `extraction-audit.json`：构建所需的提取审计摘要；公开版本移除本地绝对路径和不参与构建的网络会话材料。
- `learning-modules.json`：辅助导航分类，不作为正式教材章节。
- `supplement-explanations-a.json`、`supplement-explanations-b.json`：101 条补充解析，含逐字题干核对、官方引用链接和条号，原解析字段未覆盖。
- `questions.json`：由构建脚本生成的可读题库。
- `check-delivery.cjs`：检查原字段保留、题数、答案选项、解析覆盖和脚本语法。

原始网络响应、访客会话文件和调试材料不属于公开构建输入，也不进入发布包。公开审计摘要记载的采集结果不能等同于在其他机器重新获取或独立认证原资料。

题干、选项、原解析与来源内容的权利归原权利人。本目录第三方内容不因程序开源而取得额外版权授权。

验证边界：原数据 45,130 个单元格与提取结果比较无差异；101 条补充题干精确匹配、112 处引用条号存在。6 条待核验题及抽查的 10 条普通补充解析另作语义核对，其余补充解析未全部独立语义复核；原库 4,632 条解析未逐题事实核验。
